Stage 1 predicts Germline vs. Somatic origin only for variants ClinVar cannot already resolve confidently (XGBoost, production threshold 0.9218) — it does not itself assign pathogenicity. Stage 2's reclassification score estimates how similar a VUS is, feature-wise, to VUS that have historically been reclassified in ClinVar (submission-history-free "generalizable" model, since freshly uploaded variants have no ClinVar history yet) — read it as a triage signal, not a clinical determination. "Watch closely" = score ≥ 0.60; "Modest signal" = above the model's flat baseline; "No distinguishing signal" = exactly at baseline; "Below baseline" = below it.
